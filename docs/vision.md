# AI Shorts Factory - Visione

## Obiettivo

AI Shorts Factory è una piattaforma locale autonoma per la generazione di video short-form (TikTok, YouTube Shorts, Instagram Reels, Facebook Reels).

## Principi Fondamentali

- **Automazione completa**: la pipeline genera video da un topic fino al prodotto finale con intervento umano minimo.
- **Esecuzione locale**: tutto gira su una workstation Linux. Nessuna dipendenza da cloud o Docker.
- **Nessun ComfyUI in produzione**: solo inferenza Python nativa per massimizzare il controllo e le prestazioni.
- **Interazione tramite dashboard web**: l'utente interagisce esclusivamente tramite una dashboard web (Next.js).

## Target

Creatori di contenuti che vogliono produrre video short-form in modo automatizzato, sfruttando la potenza di calcolo locale senza costi ricorrenti cloud.
